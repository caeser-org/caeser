# Caeser v0.1.0

Caeser is a complete, shipped open source Go CI failure investigator. This release delivers a working product: it identifies the failure, establishes what the evidence shows, and ranks the functions worth inspecting.

## What is included

- A deterministic Go diagnosis pipeline: CI evidence parsing, classification, source indexing, AST and typed call analysis, bounded SSA, candidate generation and ranking, base and head comparison, and replay bundles.
- A backward causal trace that connects the observed failure to the invalid operand, its value provenance, and the producing operation. Each edge carries a relationship, a status, a source location, and evidence IDs. The trace covers local assignments, aliases, zero values, caller arguments, observed frame caller selection, and bounded multi hop wrappers.
- Defect origin hypotheses for later assignments, ignored errors, missing guards, and boundary comparisons.
- Base and head delta correlation and assertion site anchors, both informational only.
- A ranked likely function handoff, a readable investigation brief, a pull request comment with evidence in expandable details, and an optional model analysis harness that cannot change deterministic fields.
- A GitHub Action setup, a reusable workflow, a verified overlay independent holdout pipeline, and reproducible evaluation runs on hosted runners.

## Scope

- Feasibility analysis is AST and SSA value level, not full reaching definition or dominator analysis.
- The engine is weakest when several sibling functions could explain the failure, or when no implementation stack frame exists.
- Delta correlation maps changed symbols and files, not hunks or renamed lines.
- Cross package indexing and other language adapters are not part of this release.

Full detail is in `docs/capabilities.md`.

## Get started

Build from source with Go 1.26:

```sh
git clone https://github.com/caeser-org/ceaser.git
cd caeser
go build -o caeser ./cmd/caeser
./caeser version
./caeser init
./caeser evidence --ci-log failed.log > report.json
./caeser brief --report report.json
```

For continuous integration, use the reusable workflow documented in `docs/ci-integration.md`, pinned to `v0.1.0`.

## Direction

This release is the baseline. The long term goal remains evidence grounded, verified root cause diagnosis. Improvements are driven by failures on fresh independent cases.
