# v0.1.0-alpha — developer preview

**Status:** open-source developer preview. This is **not** a production
root-cause diagnosis product. It produces investigation leads with explicit
provenance and abstains when evidence is insufficient.

## What is in this alpha

- Deterministic Go pipeline: CI evidence parsing, classification, source
  indexing, AST and typed-call analysis, bounded SSA, candidate generation and
  ranking, base/head comparison, replay bundles.
- **Backward causal trace** (`CausalTrace`): observed failure → invalid operand →
  value provenance → producing operation, with per-edge relationship, status,
  source location, and evidence IDs. Includes local assignments, aliases, zero
  values, caller arguments, observed-frame caller selection, and bounded
  multi-hop wrapper chains.
- **Defect-origin hypotheses** (`DefectOrigin`): `later_assignment`,
  `ignored_error`, type-aware `missing_guard`, and collection-tied
  `boundary_guard`. All are `inferred`; none are admitted as a candidate or
  promoted to a verified cause.
- **Base/head delta correlation** (`changed` / `changed_file` / `unchanged`) and
  assertion-site anchors when no implementation frame exists — both
  informational, never causal proof.
- Ranked `likely_function` handoff, readable investigation brief, PR comment
  with evidence in expandable details, and an optional model-analysis harness
  that cannot change deterministic fields.
- GitHub Action setup, reusable workflow, verified-overlay independent holdout
  pipeline, and reproducible evaluation runs on hosted runners.

## Measured results (honest)

| Set | Cases | Exact-function |
|---|---:|---:|
| Development-exposed (used while building) | 6 | **6/6** (tracing ON) vs 5/6 OFF |
| **Independent, verified, unfamiliar repos** | 5 | **1/5 (20%)**, 1 abstention |

The 6/6 is **function localization on familiar cases**, not verified root-cause
diagnosis. The independent result is reported in full in
[INDEPENDENT-RESULTS.md](../../evaluation/final-mission/INDEPENDENT-RESULTS.md).
No general accuracy claim is made.

## Limitations (summary)

- No full reaching-definition/dominator/phi analysis; feasibility is AST + SSA
  value/path level. SSA coverage is often absent.
- Weak on sibling/fan-out ranking and on failures with no implementation frame;
  these are the two categories confirmed by the independent set.
- Delta mapping is symbol/file-level, not hunk/line-level; renames and line shifts
  are not mapped.
- No new causal verifier was added; the existing verification gates are unchanged
  and remain narrow.
- Cross-package indexing, conversion-defect derivation, and broader adapters are
  not included. Full detail: [capabilities](../../docs/capabilities.md).

## Try it

```sh
git clone https://github.com/caeser-org/ceaser.git && cd caeser
go build -o caeser ./cmd/caeser
./caeser version                       # caeser v0.1.0-alpha
./caeser init                          # in the target repository
./caeser diagnose --ci-log failed.log --artifact-first --json > report.json
./caeser brief --report report.json
```

For CI, use the [reusable workflow](../../docs/ci-integration.md) pinned to
`v0.1.0-alpha`.

## Long-term direction

The alpha is the starting point, not a reduction of the project's ambition: the
goal remains evidence-grounded, verified root-cause diagnosis. Next work is
driven by failures on fresh independent cases, not by tuning the current six.
